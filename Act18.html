1. Escenario y resumen ejecutivo

Escenario del caso: El 20/09/04, una computadora portátil Dell CPi, número de serie VLQLW, fue encontrada abandonada junto con una tarjeta PCMCIA inalámbrica y una antena externa 802.11b casera. Se sospecha que esta computadora fue utilizada con fines de piratería e interceptación de tráfico inalámbrico en puntos de acceso públicos (como Starbucks y hotspots de T-Mobile) por el sospechoso Greg Schardt, conocido en línea bajo el alias "Mr. Evil", con el objetivo de obtener números de tarjetas de crédito, nombres de usuario y contraseñas.

Conclusión principal: Los datos del sistema vinculan el equipo con el sospechoso: propietario registrado Greg Schardt, dominio primario EVIL y cuenta local "Mr. Evil". La integridad de la evidencia está verificada mediante su hash MD5. Queda pendiente revisar los artefactos de actividad (programas instalados/ejecutados, historial web, correo y archivos sospechosos) para demostrar el uso del equipo en la interceptación de tráfico.

Paso 2 Tipo de origen de datos: Disk Image or VM File

¿A qué se refiere el tipo de origen "Logical Files"? Permite agregar al caso archivos o carpetas individuales, ya sea de un disco local, una unidad de red o un dispositivo extraíble. Autopsy los lee a través del sistema operativo, por lo que solo puede analizar el contenido visible: no incluye archivos eliminados, espacio no asignado ni estructuras internas del sistema de archivos. Se utiliza para revisiones rápidas o cuando únicamente se requiere analizar un conjunto específico de archivos.

¿A qué se refiere el tipo de origen "Local Disk"? Permite analizar directamente un dispositivo físico o una partición conectada al equipo (disco duro, USB o tarjeta SD), accediendo a nivel de sector. De esta forma se incluyen los archivos eliminados, el espacio no asignado y la estructura completa del sistema de archivos. Requiere permisos de administrador y, al trabajar sobre evidencia original, debe usarse un bloqueador de escritura; por ello se recomienda crear primero una imagen forense y analizar la copia, como se hizo en esta práctica con la opción Disk Image or VM File.

El hardware encontrado junto al equipo (tarjeta PCMCIA inalámbrica y antena 802.11b) es consistente con la técnica atribuida al sospechoso: interceptar tráfico en redes Wi-Fi públicas. Asimismo, Autopsy reporta artefactos pendientes de inspección profunda: 32 programas instalados, 81 programas ejecutados, 887 registros de historial web, 2 archivos con cifrado sospechoso, 8 extensiones alteradas y 5 elementos de interés.

Limitaciones: El propietario registrado lo escribe el usuario al instalar Windows y puede ser falso; es un indicio que debe corroborarse. Hasta revisar los programas y la actividad, no se puede afirmar que el equipo se usó para interceptar información.

5. Consideraciones legales

Cadena de custodia

Cada paso se documentó con captura y se verificó el hash para demostrar que la evidencia no fue modificada. En México, el Código Nacional de Procedimientos Penales regula la cadena de custodia.

Trabajo sobre copias

El análisis se hizo sobre una imagen forense y no sobre el dispositivo original, lo que preserva la evidencia íntegra.

Autorización y privacidad

Un caso real requiere autorización legal (orden de autoridad o consentimiento del dueño) y manejo cuidadoso de datos personales como tarjetas y contraseñas.

Reproducibilidad

Documentar herramienta, versión y procedimiento permite que otro perito repita el análisis y obtenga los mismos resultados.

7. Conclusiones

La imagen analizada es íntegra y los datos del sistema operativo relacionan el equipo con Greg Schardt. Para sostener la acusación de piratería hace falta demostrar el uso de herramientas de interceptación y la obtención de datos ajenos, lo que se logrará con las líneas de investigación propuestas, empezando por las de prioridad alta.
